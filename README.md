# 小说 → 漫剧短视频 流水线 Skill（novel-to-manju）

把一个小说（或一个题材想法）做成抖音竖屏漫剧/短视频的**全流程提示词 skill**。自包含，无需其它文件，拿到就能用。

## 它是什么

一句话：**喂一篇小说，产出「爆款改文 → 漫剧剧本 → 角色卡+音色 → 人物/场景/三视图提示词 → 场景清单 → 分镜脚本 → MiniMax H3 视频提示词」**的完整流水线。

内置：
- 全流程 **10 步** + 工具分工（文字用 DeepSeek/豆包，图用即梦/MJ/SD 当参考图，视频用 MiniMax H3）
- **剧情保真原则**（最高优先级，禁止擅自删减原著剧情）
- 合规敏感词过滤（分两层：平台红线 + 题材中性化，不限制修仙/克苏鲁等题材）
- 一致性锁定（人物/场景跨镜头不变）
- 角色卡 + 音色设定（人物提示词的前置步骤，防漏角色、防撞脸）
- 场景清单（场景提示词的前置步骤，防漏场景、防前后不一致）
- 人物参考图**全 3D 渲染**（与最终视频风格统一）
- **5.1 风格总表**为全片唯一基准（题材→美术风格→色调→光影→渲染后缀）
- MiniMax H3 官方 **Ref2VA 六段式**输出模板（Shot 数量 2-4 可变）
- 打斗/技能特效、人物五官库、场景公式、三视图等全套规则
- 文件命名规范 + 最终质检清单（QC）

## 快速上手

### 用法 A：装进 Claude Code / Codex（按 `/` 调用）

**1. 安装 skill（自动触发）**
- Claude Code：把整个文件夹复制到项目或用户目录的 `.claude/skills/novel-to-manju/`
  - 项目级：`你的项目/.claude/skills/novel-to-manju/SKILL.md`
  - 用户级：`~/.claude/skills/novel-to-manju/SKILL.md`
- Codex：复制到 `.codex/skills/novel-to-manju/`

**2. 安装斜杠命令（手动 `/manju` 触发）**
- Claude Code：把 `commands/manju.md` 复制到 `.claude/commands/`（或 `~/.claude/commands/`）
- Codex：把 `commands/manju.md` 复制到 `.codex/prompts/`

**3. 使用**
- 直接说："帮我把这段小说做成漫剧"（skill 自动触发）
- 或输入 `/manju`，再粘贴小说

### 用法 B：直接粘给豆包 / DeepSeek

把 `SKILL.md` 全文复制，粘给豆包 / DeepSeek / ChatGPT，附上小说原文，它会按 10 步产出。

### 用法 C：只做某一环

说"生成男主三视图""把这段打斗写成分镜""生成 H3 视频提示词"，skill 只跑对应环节。

## 10 步总流程

1. **爆款改文**（保留原人称，做内容优化：节奏/爽点/钩子）
2. **转漫剧剧本**（强制转第一人称，做画面化处理）
3. **角色卡 + 音色设定**（整理所有角色信息，用户确认后再下一步）
4. **人物 + 道具提示词**（全 3D 渲染，半身 4:3 + 全身 9:16）
5. **场景清单**（整理所有场景，用户确认后再下一步）
6. **场景提示词**（无人纯场景，出参考图）
7. **人物三视图**（16:9，正面/侧面/背面 + 头部角度 + 局部细节）
8. **分镜 + 镜头提示词**（40-80 字/镜，禁止合并剧情节点）
9. **打斗 / 技能特效**（若有，动作链 + 连贯性 + 力量感）
10. **MiniMax H3 视频提示词**（Ref2VA 六段式，每段 4-15 秒）

## 更新日志

### v2.0 — 2026-08-17

**重大更新：剧情保真 + 流程重构 + 风格统一**

**流程重构（8 步 → 10 步）**
- 新增「角色卡 + 音色设定」环节（阶段 3）：人物提示词的前置步骤，防漏角色、防撞脸、音色全片统一
- 新增「场景清单」环节（阶段 5）：场景提示词的前置步骤，防漏场景、防前后不一致
- 明确阶段 1/2 分工：爆款改文 = 内容优化（保原人称），转漫剧剧本 = 格式转换（强制转第一人称）

**剧情保真（最高优先级）**
- 新增 2.5「剧情保真原则」：原著剧情不得擅自删减，删减仅限纯冗余，节奏靠表达密度不靠砍内容
- 单集装不下就拆多集，禁止为凑时长砍剧情
- 每步输出后必须对照原文自检，缺漏立即补回

**合规规则重构**
- 拆成两层：平台红线（绝对禁止）+ 题材中性化（允许但替换敏感词）
- 不限制题材风格：修仙/法术/阵法/克苏鲁/暗黑魔幻等正常保留，不属于封建迷信

**人物参考图全 3D**
- 去掉真人实拍版，每个角色只出 2 张全 3D 图（半身 4:3 + 全身 9:16）
- 避免 H3 生成时真人参考图导致风格混乱

**风格统一**
- 5.1 扩展为「风格总表」（题材→美术风格→色调→光影→渲染后缀），全片唯一基准
- 9.5 打斗氛围、11.4 电影风格标签改为补充引用，不得与 5.1 冲突

**其他优化**
- Ref2VA 模板 Shot 数量 2-4 可变（原固定 3 个）
- 原创小说规则扩展为通用题材（原仅限修仙）
- 删除 4.3 文案分幕 JSON（与后续流程脱节）
- 新增第 13 节「文件命名规范」
- 新增第 14 节「最终质检清单（QC）」
- 各章节加 📚 docs 引用，激活 29 个参考文件
- 精简 commands/manju.md，不再重复 8 步流程
